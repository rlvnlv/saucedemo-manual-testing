# SauceDemo — проект по ручному тестированию

## О проекте

Учебный проект по ручному тестированию веб-приложения [SauceDemo](https://www.saucedemo.com/).

Цель проекта — получить практический опыт тестирования веб-приложений, проверки пользовательских сценариев, выявления ошибок и документирования результатов.

## Объект тестирования

Веб-приложение SauceDemo — демонстрационный интернет-магазин.

## Область тестирования

В рамках проекта планируется проверить:

- Авторизацию пользователей.
- Валидацию полей ввода.
- Отображение каталога товаров.
- Сортировку товаров.
- Карточки товаров.
- Добавление и удаление товаров из корзины.
- Оформление заказа.

## Инструменты

- Ручное тестирование.
- Google Chrome / Safari.
- GitHub.
- Markdown.
