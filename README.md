# SauceDemo — Manual QA Testing

## О проекте

Учебный проект по ручному тестированию веб-приложения [SauceDemo](https://www.saucedemo.com/) — демонстрационного интернет-магазина.

Цель проекта — получить практический опыт тестирования веб-приложений, составления тестовой документации, проверки пользовательских сценариев и анализа результатов.

## Объект тестирования

Веб-приложение SauceDemo.

## Область тестирования

В рамках проекта проверены следующие функциональные области:

- Авторизация пользователей.
- Валидация полей авторизации.
- Отображение каталога товаров.
- Сортировка товаров по цене.
- Отображение карточек товаров.
- Добавление и удаление товаров из корзины.
- Оформление заказа.

## Виды тестирования

- Функциональное тестирование.
- UI-тестирование.
- Smoke-тестирование.
- Негативное тестирование.

## Тестовое окружение

- ОС: macOS.
- Браузер: Safari.
- Тип тестирования: ручное.
- Платформа: веб-приложение.
