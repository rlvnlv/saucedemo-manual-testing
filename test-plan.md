# Test Plan — SauceDemo

## 1. Цель тестирования

Проверить основные функции веб-приложения SauceDemo, выявить возможные дефекты и оценить корректность работы пользовательских сценариев.

## 2. Объект тестирования

Веб-приложение: https://www.saucedemo.com/

Тип приложения: демонстрационный интернет-магазин.

## 3. Область тестирования

Планируется проверить следующие функциональные области:

1. Авторизация пользователей.
2. Валидация полей авторизации.
3. Отображение каталога товаров.
4. Сортировка товаров.
5. Просмотр карточек товаров.
6. Добавление и удаление товаров из корзины.
7. Оформление заказа.

## 4. Виды тестирования

- Функциональное тестирование.
- UI-тестирование.
- Smoke-тестирование.
- Негативное тестирование.
- Регрессионное тестирование.

## 5. Тестовое окружение

- Браузер: Safari / Google Chrome.
- ОС: macOS.
- Тип тестирования: ручное.
- Платформа: веб-приложение.

## 6. Критерии начала тестирования

- Веб-приложение доступно.
- Основные страницы приложения загружаются.
- Тестировщику доступны тестовые учётные данные.

## 7. Критерии завершения тестирования

- Все запланированные тест-кейсы выполнены.
- Результаты тестирования задокументированы.
- Обнаруженные дефекты оформлены в виде баг-репортов.
- Итоговые результаты внесены в test-results.md.

## 8. Ограничения

Тестирование проводится на общедоступной демонстрационной версии приложения. Проверка безопасности, нагрузочное тестирование и тестирование внутренней серверной логики в рамках проекта не выполняются.
